# Aplicações web sem servidor Central

## E aplicação de web de graça dentro de uma rede onde não tem um servidor Central aqui você é o dono do seu próprio site para você recuperar seu site Você tem uma chave privada ela serve para você recuperar o seu site não é recomendado compartilhar essa chave privada
O seu site é encontrado na rede o bazar e endereço hash também o protocolo ele permite executar:html JS css
Você pode montar seu site usando esses essas linguagens você pode colocar outras linguagens com web a slimber e outras linguagens aonde você pode rodar no navegador Ricardo permite rodar aplicações como Nostr e outros modelos de servidor central de blacked ##
